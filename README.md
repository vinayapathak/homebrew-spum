# Spum for macOS

Local inference on Apple Silicon. macOS 14 or later.

Install the command-line engine:

```sh
brew install vinayapathak/spum/spum
spum --version
```

Install the standalone Mac app:

```sh
brew install --cask vinayapathak/spum/spum-app
```

Or install the command-line engine without Homebrew:

```sh
curl -fsSL https://nsimaging.ai/spum/install.sh | sh
```

Model weights are downloaded separately. See [Spum](https://nsimaging.ai/spum/) for supported models and recorded runs.
